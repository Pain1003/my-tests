# TypeScript Automation Sandbox
This repository contains my practice scripts for learning **QA Automation** on Fedora Linux.

## Technologies Used
- **Language:** TypeScript
- **Runtime:** Node.js
- **Test Runner:** Playwright
- **OS:** Fedora 44 (WSL)

## How to Run Tests
1. Install dependencies: `npm install`
2. Run all tests: `npx playwright test`
3. View report: `npx playwright show-report`
